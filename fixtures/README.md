# fixtures

| file                                          | what it is                                                                                                                                                                                                                                                                                                     |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `parc-search.json`                            | a real parc search trace ("who has built hardware? any fpga people?"), exported the way parc's admin page exports OpenTraces. Payloads were never stored, only summaries.                                                                                                                                      |
| `opencode-tally.json`                         | a real OpenCode 2.2 session (claude-sonnet-5-5) fixing `median()` in a toy repo, with an explore subagent. Converted with `@tetraslam/kiseki-adapters/opencode` from `opencode session export` of the session and its child. One harness notice listing the recording machine's tool integrations was removed. |
| `errors.json`                                 | failed calls, a call with no result, and a result with no call.                                                                                                                                                                                                                                                |
| `compare-a.json`, `compare-b.json`            | two runs of one task that agree, diverge, and agree again.                                                                                                                                                                                                                                                     |
| `subagent-parent.json`, `subagent-child.json` | a subagent stored as its own record, resolved through `loadTrace`.                                                                                                                                                                                                                                             |
| `synthetic-300.json`                          | a generated coding session with subagent branches, edits, and heavy output. The site replays it as the live demo.                                                                                                                                                                                              |
| `synthetic-10k.jsonl`                         | the same generator at 10,000 steps (28 MB). Not committed: `pnpm fixtures` writes it.                                                                                                                                                                                                                          |

Everything synthetic comes from `scripts/fixtures.mjs` and is deterministic.
